# Assistente de Contabilidade com IA

SaaS para **donos de negócio**: livros contábeis multi-usuário e multi-empresa (notas, categorias, saldos). Sem integração com órgãos fiscais na v1.

A IA explica e ajuda a operar os livros. Ela não substitui um contador.

## Stack

- Next.js App Router + TypeScript
- PostgreSQL
- Tailwind + shadcn/ui

## Status

O aplicativo ainda não foi gerado. Os scripts de desenvolvimento entram em `package.json` na primeira feature.
