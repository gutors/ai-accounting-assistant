Mode: Operate. Audience: Coordinator on a laptop during the monthly close. Prototype only.

## Direction contract

THESIS: One file is a single include; many files are a lote. The proof square names the file once. It refuses three stacked captions, a grayed Tipo select, and lote chrome on a single file.

OWN-WORLD: Ledger paper page, sheet-white in fields and the proof frame, 1px rule, 4px controls, IBM Plex Sans, Plex Mono only on the chave, caixa for Incluir documento, margem only on Retirar.

STORY: Coordinator drops one file, sees the photo with FOTO or XML in bold caps before the filename, fills the book, includes with the old primary button. A second file opens the lote toolbar. Tipo is a select only while it can still change; XML or chave locks it as a readonly field.

FIRST VIEWPORT: Header. Documentos de suporte. Incluir documento. Empty drop, or split from 768px: left proof stretches to the book through Observação (image, one-line FOTO - filename, Limpar), right 28rem book (Tipo, then origin under valor/data/favorecido, Observação), then Incluir documento. Lote adds Incluir prontos and the ruled sheet.

FORM: Evidence pane, local extension. Seed n/a.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Constraints

- Static HTML prototype. Identification is simulated.
- One file: no Incluir prontos, no lote sheet, primary Incluir documento, Limpar in the square.
- Two or more: Incluir prontos, Incluir este, Retirar, ruled lote sheet.
- Proof caption is one line under the image: bold uppercase Arquivo (FOTO or XML), then a hyphen, then the filename truncated. No separate Arquivo field. Tipo stays on the right. Origin stays under the book fields.
- From 768px the proof pane matches the book column height through Observação.
- Tipo is a native select while changeable (foto sem chave). Tipo is a readonly text field when locked (XML or chave). Not a disabled select.
